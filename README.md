# My Space Portfolio 🚀

Hey! I'm Nishant Chauhan, a B.Tech CST student at MAIT and a web developer. Welcome to my little corner of the internet.

I built this space-themed (and retro terminal-inspired) portfolio site to show off some of the stuff I've been working on, the skills I'm learning, and a bit about myself. 

### What's inside?
- **Starfield Background & Planet Orbits**: Built on top of custom HTML5 canvas code to give that space-vibe.
- **Retro CRT Overlay**: Just a touch of retro terminal aesthetics because it looks cool.
- **Terminal Component**: A simulation where you can run basic commands (type `help` to see what works!).
- **Projects & Skills**: A showcase of the coding puzzles I've solved (250+ LeetCode DSA questions and counting) and things I've built.

### Tech Stack
- **Core**: React, Vite
- **Styling**: Pure CSS (no Tailwind here, just raw CSS variables, grids, and flexbox)
- **Deployment**: Vercel
